## Data structures

- Queue: used for waiting students in FIFO order.
- Singly Linked List: used to store student service records.
- Stack: used for postfix evaluation.
- Array: used for service time statistics.

## Sorting algorithms

- Selection Sort: repeatedly selects the smallest remaining value.
- Insertion Sort: inserts each next value into its sorted position.
- Merge Sort: divides and merges.
- Quick Sort: uses a pivot and partitions the array.

## Experiment results

The project includes a sorting experiment for sizes 20, 50, 100, and 500, plus an almost-sorted 100-element array.

## Integrated system

The Java program presents a Campus Service Centre menu and uses the queue, linked list, array, and sorting implementations together.

## Pseudocode

Queue:
- enqueue: add to rear
- dequeue: remove from front

Stack:
- push: add to top
- pop: remove from top
- postfix evaluation: push numbers; pop operands for operators

Linked list:
- insertNode: add at start, end, or specified position
- deleteNode: remove matching student
- searchNode: walk through list
- traverseList: print records

Sorting:
- selectionSort: select minimum and swap
- insertionSort: insert into sorted subarray
- mergeSort: divide and merge
- quickSort: partition around pivot
