## How to compile and run
1. Open a terminal in the project folder.
2. Compile all Java source files:
   javac -d out $(find src -name "*.java")
3. Run the integrated service centre program:
   java -cp out Main
4. Run the independent postfix exercise:
   java -cp out stack.PostfixDemo
