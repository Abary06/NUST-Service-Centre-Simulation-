## How to compile and run
Install a JDK, open PowerShell in the project folder, and run:

```powershell
$sources = Get-ChildItem src -Recurse -Filter *.java | ForEach-Object { $_.FullName }
javac -d out $sources
java -cp out Main
```

To run the independent postfix exercise instead, use:

```powershell
java -cp out stack.PostfixDemo
```
